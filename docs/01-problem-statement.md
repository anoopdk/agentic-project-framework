# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Platform Engineering Client
- **Engagement type:** Framework / Methodology Delivery

## Business problem

The Platform Engineering Client needed a human-governed framework so AI coding agents and engineers follow a consistent Discover -> Decide -> Build -> Validate -> Record -> Align lifecycle with explicit approval gates, especially for data engineering work.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
